# ColonySim


![Game View](https://github.com/amJohnnyma/ColonySimGodot)


## Installation - Linux only 
**SFML**
```
sudo apt update
```
```
sudo apt install libsfml-dev
```

**Install**
```
git clone https://github.com/amJohnnyma/ColonySim.git
```
**Build**
```
make clean
```
```
make
```
```
make run
```

## Controls
* E: Zoom out
* Q: Zoom in
* W: Move up
* A: Move left
* S: Move down
* D: Move right
* P: Pause/Unpause
